# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/psenger/multivalue-map/security/advisories/new).

Include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions
- Any suggested mitigations

You will receive a response within 7 days. If the report is accepted, a fix will be prioritised and a coordinated disclosure timeline agreed with you before any public announcement.
